# RPS-AI - Adaptive Pattern Recognition & Game Intelligence

Interactive Rock-Paper-Scissors platform powered by Markov chain transition modeling and machine learning pattern recognition.

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Streamlit](https://img.shields.io/badge/Streamlit-1.32%2B-FF4B4B?logo=streamlit&logoColor=white)](https://streamlit.io)
[![Author](https://img.shields.io/badge/Author-Dheeraj%20Muley-black?logo=github)](https://github.com/dheeraj815)

## Key Features
- **Adaptive Opponent AI**: Learns user behavioral heuristics and transition probabilities in real time
- **Multi-Order Markov Chains**: Predicts next choice using historical sequence n-grams
- **Performance Telemetry**: Win/loss/tie ratios, strategy win streaks, and probability heatmaps
- **Interactive UI**: Responsive gameplay animations and statistics dashboard
